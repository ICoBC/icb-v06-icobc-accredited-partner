# Contributing to this course 🤝

Thank you for helping to improve this ICoBC course. Every change is reviewed before it is published.

## How to propose a change

1. **Small fix?** Open `README.md` on GitHub, select ✏️ *Edit*, make the change and choose *Propose changes*. GitHub creates a branch and a pull request for you.
2. **Larger change?** Open an issue first (📝 *Content correction* or ♿ *Accessibility issue*) so that the editors can agree the approach.
3. Fill in the pull request checklist. The automatic check runs on every pull request.
4. A subject-matter reviewer and an ICoBC editor approve the pull request. Only then is it merged into `main`.

## Writing rules in brief

- British English: *recognise*, *organisation*, *licence* (noun), *programme*, *per cent*, dates as *4 November 2026*.
- Address learners as *you*; use *they* for people in general.
- Short sentences, active voice, one idea per paragraph.
- No exclamation marks in quiz feedback.
- Name sources and dates for facts that can change.

## LiaScript syntax used here

| Element | Syntax |
|---|---|
| Single-choice quiz | `- [( )] wrong` and `- [(X)] correct` |
| Task list | `- [ ] item` |
| Collapsible section | `<details><summary>Title</summary> … </details>` |
| Block marker (for the round trip back to SCORM) | `<!-- block: tabs -->` |

Do not remove the `<!-- block: … -->` and `<!-- icb-meta: … -->` comments: the ICoBC Course Workshop needs them to rebuild the SCORM package.
