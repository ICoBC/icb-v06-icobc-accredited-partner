# Review guide 🔍

Use this guide when you review a pull request for this course.

| Check | Question |
|---|---|
| ✅ Accuracy | Are all facts correct and backed by named, current sources? |
| 🎯 Objectives | Do the content and the quizzes still serve the learning objectives? |
| 🇬🇧 Language | Is the text in clear British English, inclusive and free of jargon? |
| 🧩 Quizzes | Exactly one correct answer, plausible distractors, helpful feedback for every option? |
| ♿ Accessibility | Headings in order, alt text for images, no information conveyed by colour alone? |
| ©️ Rights | Are images and quotations cleared? Are ICoBC brand assets used as agreed? |

Approve only when every row is answered with *yes*. Otherwise, request changes and explain why.
